## 📖 About BuyHive

**BuyHive** is a modern group-buying and shared purchasing platform designed primarily for university students and budget-conscious communities.

The platform allows users to create or join purchasing groups to reduce product costs and delivery expenses through collective buying.

Instead of buying individually, users can collaborate with others who want the same product and share both the purchase price and shipping costs.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/jahidul-islam-dev/buyhive-ui.git
```

Navigate to the project:

```bash
cd buyhive-ui
```

Install dependencies:

```bash
pnpm install
```

Run development server:

```bash
pnpm dev
```

Open:

```text
http://localhost:3000
```
