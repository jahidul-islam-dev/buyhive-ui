Project: BuyHive

Purpose:
A university student group-buying app where users can create or join groups to purchase products together and reduce costs.

Features:
- User registration/login
- Guest mode
- Home screen
- Explore products
- Search
- Category filters
- Create group
- Join group
- Group progress
- Notifications
- Profile page
- Student verification
- Payment flow
- Order history
- Group chat
- Ratings and reviews

Categories:
- Electronics
- Books
- Food
- Components
- Others

Design:
- Modern
- Airbnb-like
- Blue + Green theme
- Rounded corners
- Mobile-first
